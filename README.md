# Pharma ERP Enterprise v5.7.2 — Administration & Accounting

نظام إداري ومالي للمؤسسة، يركز على الخزائن والحسابات والإيرادات والمصروفات والموردين والموظفين والرواتب والتقارير والصلاحيات والاعتمادات والتنبيهات والتدقيق.

وحدات المبيعات القديمة محفوظة للتوافق والرجوع الآمن، لكنها ليست محور التطوير الحالي.

## تشغيل آمن على Windows

```bat
python -m venv venv
venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python app.py
```

ثم افتح:

```text
http://127.0.0.1:5000
```

## إعدادات اختيارية

يمكن ضبط متغيرات البيئة التالية قبل التشغيل:

- `SECRET_KEY`: مفتاح طويل وعشوائي للجلسات، وهو مطلوب للإنتاج.
- `PHARMA_DB_PATH`: مسار قاعدة البيانات. الافتراضي `pharmacy_finance.db` داخل المشروع.
- `FLASK_DEBUG`: اجعله `1` للتطوير فقط. الافتراضي `0`.
- `HOST`: الافتراضي `127.0.0.1`.
- `PORT`: الافتراضي `5000`.

مثال Windows CMD:

```bat
set SECRET_KEY=ضع-هنا-مفتاحا-طويلا-وعشوائيا
set FLASK_DEBUG=0
python app.py
```

## قاعدة البيانات والنسخ الاحتياطي

- لا تستبدل `pharmacy_finance.db` عند تحديث ملفات البرنامج إذا كانت تحتوي بياناتك الفعلية.
- خذ نسخة احتياطية قبل كل تحديث.
- لا تنسخ ملفات قاعدة بيانات من داخل `__pycache__` أو مجلدات مؤقتة؛ قاعدة البيانات المعتمدة هي الموجودة في جذر المشروع أو المسار المحدد في `PHARMA_DB_PATH`.

## الاختبارات

بعد تثبيت المتطلبات:

```bat
python -m pytest -q
```

## ملاحظات التوزيع

لا تضمّن هذه المجلدات داخل ملف الإصدار:

- `venv`
- `__pycache__`
- `.pytest_cache`

بيانات الدخول الافتراضية الموجودة في النسخ التطويرية يجب تغييرها قبل الاستخدام الفعلي.
