# Pharma ERP Enterprise v5.3.0-dev

## Approval Engine

- Added approval definitions, requests, and immutable approval history.
- Added permissions for viewing, configuring, and deciding approvals.
- Added Approval Center with pending/approved/rejected filters.
- Added approval request detail and approve/reject actions with notes.
- Integrated treasury transfers: non-admin submissions go to approval; approval sends the transfer to receiving.
- Kept the admin emergency bypass to preserve administrative continuity.
- Added notifications, tasks, audit entries, and regression tests.
